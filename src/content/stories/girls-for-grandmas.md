# The Girls for Grandmas

The CrossFit community has a set of benchmark workouts named after women — Fran, Diane, Elizabeth, and others. They're brutal. They test everything.

Then someone came up with a version for grandmothers. Same structure. Scaled exercises. Same principles.

The point: the workout doesn't change. Only the load and the variation change. A scaled push-up done by a grandmother uses the same movement pattern as a handstand push-up done by an elite athlete.

The needs of a grandmother and the needs of an Olympic athlete differ by degree, not kind.
