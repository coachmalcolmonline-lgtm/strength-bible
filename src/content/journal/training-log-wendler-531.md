# Training Log — Wendler 5/3/1

Living journal for athletes running Wendler 5/3/1. Four-week cycles. Each
cycle has one day per lift. Log the three main sets, the AMRAP reps, and the
RPE. Recalculate Training Maxes at the end of each cycle.

## How to Use This Log

1. Before each session, note your Training Max for the lift.
2. Log all three main sets (weight and reps).
3. Log the AMRAP set — this drives progression.
4. Note RPE on the AMRAP.
5. Recalculate Training Max at the end of the cycle.

## Progression Reminders

- Training Max = 90% of true 1RM.
- Add 5 lbs (Press, Bench) or 10 lbs (Squat, Deadlift) after each successful cycle.
- If a cycle fails, drop Training Max by 10% and rebuild.
