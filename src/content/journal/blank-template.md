# Blank Template

A modular, blank journal page. Duplicate it, rename it, and fill in whatever you need. It's the escape hatch for Phase 2+ content — conditioning logs, sport-specific tracking, contest prep, whatever the program grows into.

## When to Use This

- You want to track something the existing templates don't cover
- You're testing a new log format before asking for a proper template
- You're running a program that isn't pre-loaded (yet)
- You want a scratch page for a single experiment

## How to Make It Yours

1. Copy this file: `cp src/content/journal/blank-template.md src/content/journal/my-new-log.md`
2. Edit the frontmatter — change `title`, `icon`, `order` (pick a number above 18)
3. Update the fields and log table
4. Run `./scripts/checkpoint.sh "Add my-new-log template"`
5. It appears in the Journal index automatically
